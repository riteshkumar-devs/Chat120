Built with Complete Privacy Architecture

No telemetry, no account passwords, zero permanent logs.

⏱️

120-Minute Ephemeral Lifecycle

By default, all user documents, guest IDs, message logs, and files auto-destruct after 120 minutes. Optionally configure custom lifetimes or execute a 1-click permanent wipe.

🛡️

Client-Side AES-256-GCM

Messages and code snippets are encrypted directly in browser memory using the Web Crypto API with 256-bit keys and unique 12-byte IVs before transmission to the database.

☁️

100MB File Transfers

Share high-resolution videos, full raw log archives, database dumps, and zip files up to 100MB with real-time progress status feedback.

💻

10,000+ Line Code Viewer

Built for developers. Share multi-thousand line snippets with VS Code dark syntax formatting, line numbers, custom language tagging, and fullscreen inspection.

📞

Encrypted WebRTC Voice

Peer-to-peer crystal clear audio calling secured by DTLS-SRTP encryption, active call duration timers, mute controls, and participant indicators.

📱

QR Code Peer Discovery

Instant direct connection by scanning a peer's personal QR code or sharing a 6-digit room code without revealing any email addresses or phone numbers.
